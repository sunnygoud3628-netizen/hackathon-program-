Why measurements differ from theory

  • Constant factors and memory access patterns
  • Python/JS interpreter overhead
  • Cache locality (Merge Sort uses extra memory)
  • Pivot selection quality in Quick Sort
  • Small n is dominated by overhead

Counting Rules

  • Every element comparison = 1 comparison
  • Every exchange of two elements = 1 swap
  • Every write during merge = 1 move
